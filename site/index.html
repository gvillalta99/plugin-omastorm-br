◈OMASTORM Beta 0.1.2
KJAX Jacksonville Reflectivity / 0.5° / Live

Live NEXRAD radar for the Omarchy desktop. Every site in the network, drawn from the measured data in the monospace pixel language of the shell.

  • Live. Sweeps paint as the antenna turns. Stale data says so.
  • Every site. Pan and the map follows the nearest station, or search by id, city, or state.
  • Timeline. The last 60 scans per station, cached. Play, step, scrub.
  • Native. Colors, font, and spacing come from your Omarchy theme and change with it.
  • Keyboard first. Every control is a keystroke, and every key is rebindable.
  • Honest. Actual scan times. No forecasts, no mosaic, no vendor grid.
Install Omarchy 4 · x86_64 
$ omarchy plugin add https://github.com/wesleygrimes/omastorm --enable
  1. Pick a bar section when asked. The mark appears in the bar; click it for the popover, the home station, and the actual scan time.
  2. First open fetches the pinned engine binary from GitHub Releases, checks its sha256, and keeps it under ~/.local/share/omastorm. Nothing else leaves the plugin's own directories.
  3. Expand for the window: every site, the timeline, three treatments. Press ? for the keys.
-- ~/.config/hypr/bindings.lua, optional: open the window from the keyboard
o.bind("SUPER + SHIFT + R", "Omastorm", "omarchy shell shell toggle com.omastorm.radar '{}'")

Update with omarchy plugin update com.omastorm.radar. The README covers configuration, the key table, and removal. This is a beta; rough edges go to GitHub issues.
